**Date:** 2026-08-18  
**Status:** Approved for Implementation  
**Version:** 1.0.0-Enterprise  

---

## 1. Executive Summary & Vision

**39POS** is a premier, offline-first, cloud-synchronized enterprise Point of Sale (POS) and Enterprise Resource Planning (ERP) platform built with **React 18 + TypeScript + Vite + Tailwind CSS + Material UI** on the frontend, a high-performance **Node.js / Express REST API** backend, and a dual-dialect database architecture powered by **Drizzle ORM** (local SQLite for fast zero-latency offline operation + cloud PostgreSQL for multi-store centralized reporting and data warehouse sync).

The system is engineered for multi-vertical businesses:
1. **Retail & Supermarkets:** Rapid barcode/QR scanning, unit conversions, wholesale/retail pricing, batch management.
2. **Restaurants & Cafés:** Hold/Resume bills, kitchen tickets (KOT), split tender payments, table ordering.
3. **Pharmacies & Healthcare:** Expiry date tracking, batch/serial tracking, prescription alerts.
4. **Warehouses & Wholesalers:** FIFO/LIFO/Average cost valuation, inter-warehouse transfers, supplier PO workflows.

## 6. Multi-Currency Engine

1. Supports 11 Core Currencies: `LAK`, `THB`, `USD`, `EUR`, `CNY`, `JPY`, `KRW`, `SGD`, `MYR`, `VND`, `KHR`.
2. Decimal.js calculation wrapper preventing floating point drift.
3. Multi-tender split currency: e.g. Customer bill is $10.00 USD, paid with 200,000 LAK and 100 THB; system computes exact change in preferred local currency.
4. Auto-update and manual rate override matrix with historical audit recording.

---

## 7. Hardware Peripherals & POS Terminal Suite

1. **ESC/POS Generator:** Converts cart receipts into standard 80mm and 58mm raw ESC/POS byte buffers for network TCP (port 9100), USB (WebUSB), and Serial (WebSerial) thermal printers.
2. **Barcode Scanner:** Global listener buffer handling 1D/2D HID wedge scanners with configurable debounce (30ms), enter prefix/suffix detection, and camera-based QR scanner.
3. **Cash Drawer:** RJ11 pulse command generation (`ESC p 0 25 250`) on successful cash sale completion.
4. **Dual Display (Customer Facing):** Real-time broadcast channel / WebSocket mirror showing cart items, promotional slides, and QR payment dynamic code.

---

## 8. Offline-First Synchronization Architecture

1. **Write Local First:** Every sale, stock update, and customer edit is committed immediately to the local SQLite database.
2. **Sync Queue:** Mutations are assigned a UUID v4 and high-precision millisecond timestamp `client_updated_at`.
3. **Background Worker:** Runs every 15 seconds (or on reconnect), sending batches to `/api/sync/push`.
4. **Conflict Resolution:** Last-Write-Wins (LWW) with server authority and soft-delete tombstone flags.

---

## 9. Security & Role-Based Access Control (RBAC)

1. **Dual-Auth:** Full JWT Access (15m) + HttpOnly Refresh Token (7d) for backend access + 4-digit Cashier PIN for rapid on-register unlock and shift changes.
2. **Audit Trails:** Automatic interceptor capturing actor ID, IP, route, payload diff (`old_values`, `new_values`), and timestamp.
3. **AES-256-GCM Encryption:** For sensitive fields, backup archives, and cloud exports.
4. **OWASP Protections:** Helmet security headers, CORS origin whitelisting, rate limiting on auth endpoints, parameter sanitization against SQLi and XSS.

---

## 10. Document Generation & Backup Engine

1. **Excel Export (.xlsx):** ExcelJS with custom header styling, auto-column sizing, currency formatting, and multi-sheet summaries.
2. **Word Export (.docx):** docx-templates for quotations, purchase orders, and supplier agreements.
3. **PDF Generator (.pdf):** High-definition thermal receipt and A4 tax invoice rendering with embedded Unicode font subsets (Noto Sans Lao/Thai/JP/ZH).
4. **Automated Backup Runner:** Scheduled cron (Daily, Weekly, Monthly) generating compressed and encrypted `.zip`, `.sql`, or `.json` archives to user-configured paths (Local, NAS, USB, AWS S3, Cloudflare R2).
